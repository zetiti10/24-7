# Home Assistant App: 24-7

24-7 is a small Minecraft bot system to constantly load an area. 

It features:
- a config file to configure multiple accounts and servers
- a connection function for newers versions of the authMe plugin using the new Dialog feature
- a web interface to enable and disable bots, and to control it
- a control by /msg system with a list of allowed players in the config

Warning: this app is in beta and future development isn't planned!
